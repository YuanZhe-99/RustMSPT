# 网格裁剪与体积分数统计

堆积管线需要知道有多少固体材料实际位于堆积盒内——不是每个颗粒网格的总体积，而是每个颗粒*限定在盒内*的体积部分，因为颗粒经常被允许跨越域边界（边界模式 2 和 3）。要得到这个数值，需要将每个颗粒网格与盒进行裁剪并测量剩余部分的体积，同时保持结果足够封闭，使得后续通过散度定理进行的体积计算是有意义的。`src/geometry/volume.rs` 端到端地实现了这一点：一个基于 Sutherland-Hodgman 算法的网格/平面裁剪器、一个由六次连续平面裁剪构建的盒裁剪包装函数，以及构建于其上的体积分数（VF）指标。

## 将网格与单个平面裁剪

原子操作是 `clip_mesh_by_plane_with_cap`，它将整个网格与一个半空间（由平面 `origin` 和外向 `normal` 定义）进行裁剪，并返回一个新的、仍然封闭的网格。它由几个较小的部分构建而成：

1. **有符号距离分类**（`clip_plane_signed_distance`）。每个顶点通过 `(p - origin) · normal` 进行分类：非负表示"内部"（保留侧），负表示"外部"（被裁掉）。
2. **Sutherland-Hodgman 多边形裁剪**（`clip_polygon_with_plane`）。每个三角形被当作一个 3 顶点多边形遍历；对于多边形的每条边 `(c, n)`，根据每个端点是在半空间内部还是外部，应用四种经典的 Sutherland-Hodgman 情况：
   - 内部 → 内部：保留第二个顶点。
   - 内部 → 外部：仅输出插值得到的交点。
   - 外部 → 内部：先输出插值得到的交点，再输出第二个顶点。
   - 外部 → 外部：不输出任何内容。

   插值点来自 `clip_segment_plane_intersection`，它使用两个端点的有符号距离沿线段进行线性插值（`t = da / (da - db)`，并裁剪到 `[0, 1]` 范围内）——这是标准的平面/线段求交公式。由于一个三角形裁剪后可能产生 0 到 4 个顶点，因此在重新组装被裁剪的网格主体时，输出多边形以简单扇形方式进行三角剖分（`for i in 1..(clipped_poly.len() - 1)`）。
3. **跨平面线段提取**（`collect_triangle_plane_segment`）。对每个原始三角形，此步骤独立地找出该平面实际穿越三角形边界的位置（顶点距离接近零，或边的两个端点位于平面两侧），并将其记录为一条两点线段。这些线段是修复裁剪过程在网格表面切出的孔洞所需的原始材料。
4. **盖面三角剖分**（`plane_basis`、`triangulate_cap_from_segments`）。仅仅丢弃网格的外部部分会在平面切过的地方留下一个开放边界——网格不再封闭，此时通过 `mesh_volume` 中散度定理公式计算的体积在这样一个开放表面上是没有意义的。为了保持结果封闭，第 3 步中收集的所有跨平面线段会被拼接成一个**盖面**：`plane_basis` 计算出与裁剪法线正交的平面内 2D 基 `(u, v)`，这些线段被合并为一个基于去重端点索引的邻接图，`triangulate_cap_from_segments` 遍历该图以找出闭合环（围住孔洞的多边形环），在 `(u, v)` 平面内按各环的质心对其顶点进行角度排序，并从质心以匹配裁剪法线朝向的绕序进行扇形三角剖分。裁剪后的网格主体和其盖面被合并（`merge_meshes`）为一个封闭网格。

## 从单个平面到一个盒：`clip_mesh_by_bbox`

`clip_mesh_by_bbox` 通过依次应用六次 `clip_mesh_by_plane_with_cap`（每个盒面一次：`min.x`/`max.x`、`min.y`/`max.y`、`min.z`/`max.z`，各自使用相应的内向法线）将网格裁剪到一个轴对齐的盒内。由于每次单独的平面裁剪都会重新为自身产生的开放边界加盖，因此网格在六次裁剪的每一步之后都保持封闭——不仅仅是在最后——所以中间状态始终是有效的封闭网格，并且如果网格在六个平面裁剪过程中途已被完全裁掉，该函数可以提前短路退出（`if out.is_empty() { break; }`）。结果就是输入网格中位于盒内的部分，是一个封闭的、可计算体积的网格。

## 体积分数统计

体积分数直接构建在盒裁剪之上：

- `particle_volume_in_bbox(mesh, bbox)` = `mesh_volume(clip_mesh_by_bbox(mesh, bbox))`——将颗粒裁剪到盒内，然后通过 `mesh_volume` 中基于有符号四面体的散度定理求和方式测量其体积。
- `volume_fraction_of_meshes_in_bbox(meshes, bbox)` 计算整个颗粒群体的聚合体积分数（VF）。它使用 `rayon` 的 `par_iter` 在多个网格上并行运行，对每个网格首先拆分为连通分量（`split_mesh_into_granules`）——单个输入"网格"可能代表若干个互不相连的颗粒（granule）——并对每个颗粒分量分别求和 `particle_volume_in_bbox`（如果拆分未发现任何分量，则退化为将整个网格视为一个整体处理）。所有按网格计算的裁剪体积被求和后，除以盒体积（`bbox.volume()`，为避免除零而下限设为 `1e-12`），并将结果裁剪到 `[0, 1]` 范围内。
- `volume_fraction_in_bbox` 是单网格版本的便捷包装函数。

这一体积分数计算是堆积、优化和测量管线共同依赖的核心指标：堆积管线用它来跟踪向 `target_volume_fraction` 迈进的进度并决定何时判定盒已装满；优化管线将体积分数的接近程度折入模拟退火所最小化的损失/目标函数中；测量管线则将体积分数作为一项重要的输出统计量进行报告。根据 `AGENTS.md` 的约定，对于边界模式 2 和 3，粒径和球形度指标是基于完整的、未裁剪的网格计算的，而体积分数则始终专门使用盒内裁剪后的体积进行核算——因此，一个突出盒外的颗粒会以其完整大小贡献于形状统计，但只以其裁剪后的部分贡献于体积分数。

## 通过量化键进行顶点去重

盖面三角剖分需要合并那些独立计算得出（每个三角形计算一次）但实际代表裁剪平面上同一物理点的线段端点，而浮点数相等判断对此并不可靠。`quantize_point_key` 通过将每个坐标四舍五入为一个固定精度的整数键（`(x * 1e6).round() as i64`，`y`/`z` 同理）来规避此问题，并将该元组用作哈希表的键——两个坐标值在大约 `1e-6` 单位精度范围内一致的点会被合并为同一个顶点。这与 STL 网格加载器（`src/io/stl.rs` 中的 `quantize_key` / `dedup_vertex`）在将三角形集合解析为带索引网格时用于合并重合顶点所独立采用的容差去重技巧完全相同——两者都是将浮点几何转换为一致拓扑结构时反复出现的"对齐网格"（snap-to-grid）模式的具体实例。

### 无实际切割时的体积快路径

私有平面裁剪器消费 mesh，按面引用的顶点和既有 distance >= -1e-9 判据分类。全部在内（包括相切）直接返回原分配，不生成封口；全部在外返回空；混合情况保留既有多边形/封口算法。修复完全位于域内且贴面时的重复封口，未被面引用的外部顶点不产生切割。clip_mesh_by_bbox 移动中间 mesh；particle_volume_in_bbox 对所有存储顶点都在盒内的情况直接算原网格体积，避免克隆与六次裁剪。测试覆盖内/外绕序、平移、重合边界、外向盒部分交集、未引用外部顶点。此改动不替代 legacy 部分切割封口算法，也未证明其对任意非凸/嵌套截面正确。
