# 四面体网格修复

`tet-repair` 子命令修复四面体网格中求解器无法接受的单元（翻转单元和长宽比超限的单元），手段是翻转和移动节点，且不改变网格任何部分所属的材料。它是 simHelper `meshing/tet_repair.flip_repair`（闭合修复的一部分）的原生实现：在 1,152,074 个单元的闭合网格上，一次在 Python 中要几分钟的修复，这里只用 0.24 s；Python 的时间主要花在为每个节点建集合和逐个单元求质量上。

## 质量

长宽比采用 YAFEQ 的定义（`MESH_verification`）：外接球半径除以三倍内切球半径，正四面体为 1；外接球半径由 `|u|²(v×w) + |v|²(w×u) + |w|²(u×v)| / 12|V|` 求得，`u, v, w` 为到第四个顶点的边。`|V| <= 1e-30` 的单元长宽比为无穷大；体积不为正或长宽比超过 `limit` 的单元为*坏单元*。

## 规则

1. **填充区。** 给出 `padding` 时，体积为零（`|V| <= 1e-9 L³`，`L` 为最长边）、有一个面贴着填充区单元、且四个角都在填充区单元上的坏单元划给填充区。有一个角在体内的扁单元不划出去：划走之后，体的外表面上会留下一条伸到那个角、厚度为零的缝。
2. **翻转**：按最差的被监视单元优先、分轮（最多 `sweeps` 轮）进行：穿过与同材料单个单元共享的面做 2-3，绕三单元棱做 3-2，绕四单元棱做 4-4（两条对角线都试）。当所有新单元为正、被替换单元的有向体积守恒（相对 `1e-9`）、且新的最差长宽比低于原来的最差值时采用；最差新长宽比最低者胜出。从不在不同材料之间翻转，也从不去掉三个节点都固定的面、两个节点都固定的棱、或该棱与一个环节点构成的全固定面。
3. **移动。** 仍为坏单元的被监视单元，移动它的一个节点到周围单元全为正且超限总量最小的位置（从节点处和从邻点均值处各做两次 Nelder-Mead，`xatol`/`fatol` 先 `1e-6` 后 `1e-7`），前提是比现在小。自由节点（周围只有一种材料）可任意移动；`wall_tol > 0` 时，两种材料之间的节点只能在它们之间的面 `wall_tol` 范围内移动，`layer` 面上的固定节点只能在这些面 `wall_tol` 范围内移动。包围盒上的节点不动。
4. 翻转和移动交替进行，直到两者都无效，最多四次。
5. **联动修复。** 仍然翻转的单元按共享节点分组，同时移动组内所有可动节点（两种材料之间的节点沿其壁，层节点沿其层，壁上的层节点同时沿两者，范围为 `joint_tol`）：用以 `seed` 为种子的 ChaCha8 生成器做 20,000 次随机试探，步长从组平均边长的 0.4 逐渐缩小，然后做 Nelder-Mead；当周围没有翻转单元且得分改善时采用。之后再做翻转和移动。

Nelder-Mead 与 scipy 的非自适应版本相同（反射 1、扩张 2、收缩和缩小 0.5；初始单纯形每个坐标增加 5 %，为零的坐标取 0.00025）。在上述闭合网格上，每一次翻转和每一次 Nelder-Mead 移动都与 simHelper 的 Python 修复相同（精确到报告的四位小数）。

## 与 simHelper Python 版的不同

两处，都是在同样合格的修复之间的选择，结果不会更差：

- **并列时的顺序。** 被监视单元按最差优先访问；长宽比相同的单元（所有翻转单元都并列为无穷大）在这里按编号顺序，在 Python 中按集合顺序。
- **联动修复的随机数**在这里来自有种子的 ChaCha8 生成器，在 Python 中来自 numpy，所以随机搜索落在别处。在该闭合网格上，它移动的两个节点与 Python 的结果相差 0.06 和 0.37 µm，两边都没有翻转单元、也没有超限单元。

给定种子时运行是确定的，与线程数无关。

## 并行

修复本身是顺序的（每次翻转或移动都会改变下一步看到的网格，而坏单元只有少数几个），所以耗时在原生运算，不在线程。全网格的步骤（所有单元的初始质量、查找翻转单元、最终统计）在本次运行自己的线程池（`cpu_max`）中用 rayon 并行。没有 GPU 路径：原生重写之后剩下的是几千次局部求值，低于一次分派的开销。

## 输入与输出

运行示例见 [`examples/tet-repair.md`](../examples/tet-repair.md)，函数见 [`reference/pipeline-tet-repair.md`](../reference/pipeline-tet-repair.md)。数组以 `.npy` 文件传递：`points` `(n, 3)` f64；`tets` `(m, 4)`、`density` `(m)`、`fixed` `(n)`（0/1）为非负整数；可选 `layer` `(k, 3)`。输出为 `points.npy`、`tets.npy`（int64，按顺序为存活单元：输入中保留的单元，再接翻转生成的单元）、`density.npy`（int64）和 `report.json`（`method_version` `tet-repair-v1`、构建标识、参数、计数、修复报告——修复前的坏单元、划给填充区的单元、每次翻转、每个移动的节点、之后的翻转和超限单元数、之后的最差长宽比（不计填充区）——以及耗时）。
